# Generic early-warning signals are at chance under a matched false-alarm protocol

The methodological / negative-result manuscript of the pair: one
matched-false-alarm, label-permutation evaluation protocol applied
unchanged to four physical corpora (scalp-EEG seizures, cardiac AF
onsets, power-grid growing oscillations, palaeoclimate transitions) and
a molecular fifth modality (dynamical-network-biomarker indices), with
the canonical Dakos AR(1)-Kendall-tau detector run head-to-head on the
identical segments. No detector reaches significance in any domain; the
nulls bound demonstrated skill at these corpus sizes, and every alarm
and non-detection is sealed in content-addressed evidence records.

[10.5281/zenodo.22113062](https://doi.org/10.5281/zenodo.22113062)
