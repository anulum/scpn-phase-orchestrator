# Papers

Canonical manuscript collection of this repository (fleet-standard
structure). Each submission lives in one numbered, self-contained
directory under `submissions/`; a clean checkout rebuilds every
`manuscript.pdf` with plain TeX Live (`pdflatex`, two passes). All
quantitative claims in every manuscript bind to the hash-sealed,
byte-reproducible evidence artefacts under `examples/real_data/`.

See `submissions/README.md` for the index.
