# Native output fault fixture

This non-publishable PyO3 crate implements invalid outputs solely to verify the
Python wrappers' defensive contracts. It implements no numerical solver. The
genuine numerical kernel and the genuinely absent fallback remain independent
obligatory profiles.

The default build exports deliberately defective E/I, sheaf and sparse producers.
The `--no-default-features` build genuinely omits the stepper classes. Both builds
have distribution name `spo-native-output-fixture`, version `0.0.0`, and explicit
module marker `SPO_NATIVE_OUTPUT_FAULT_FIXTURE_V1`. The import name `spo_kernel`
exercises the unchanged production import boundary in a separate installation
where the genuine kernel is not installed.

The reviewed disposition names exactly 13 statements and eight branch
outcomes. Coverage from this profile may add only those reviewed guards after
the independently measured native-plus-absent union. Each residual is bound to
the current source line hash. Changed source, missing profiles, statement-only
coverage or any unexplained extra credit must fail admission.

Run `output_contracts.py` only in the marked defective-output installation.
Run `missing_classes_contracts.py` in both the genuine-absence and marked
missing-class installations. They use public engine calls and independent
zero-coupling Euler oracles. No module, capability flag or engine is monkeypatched.

The fixture crate, wheels and shared objects must never enter the project wheel,
source distribution or any published artifact. The committed fixture Cargo lock
must be audited by the required CI audit job with the other dependency locks.
